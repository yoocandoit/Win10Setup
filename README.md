## 🧩 Components
This repository includes configuration for:
- **Status Bar**: `YASB`
- **Window Managers**: `GlazeWM`
- **Terminals**: `Window Terminal`
- **Taskbar**: `TranslucentTB`
- **System Fetch**: `Fastfetch`
- **File Explorer Blur**: `ExplorerBlurMica`
- **Audio visualizer**: `cava`
